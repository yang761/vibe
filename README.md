# Learning Timer Application

## Overview
The Learning Timer is a versatile application designed to help users manage their learning time effectively. It features flexible timers, reminders, and tracking functionalities to optimize study sessions.

## Features
- **Custom Timers:** Set timers for different learning activities.
- **Progress Tracking:** Keep track of completed sessions and time spent on each activity.
- **Reminders:** Set alerts for study breaks and session end times.
- **User-Friendly Interface:** An intuitive layout for seamless navigation.
  
## Usage Instructions
1. **Installation:** Clone the repository and navigate into the project directory.
   ```bash
   git clone https://github.com/yang761/vibe.git
   cd vibe
   ```
2. **Run the Application:** Execute the main script to launch the application.
   ```bash
   python main.py
   ```
3. **Setting a Timer:** Enter the desired time interval and select the corresponding activity to start the timer.
4. **Viewing Progress:** Access the progress dashboard to view past learning sessions.

## Technical Details
- **Programming Language:** Python
- **Libraries Used:**
  - `tkinter` for GUI
  - `datetime` for time management
- **File Structure:**
  - `main.py`: Main application script.
  - `timer.py`: Contains timer functionalities.
  - `tracker.py`: Manages user progress and data storage.

## Conclusion
The Learning Timer application is a powerful tool for anyone looking to enhance their learning efficiency. With its customized features and tracking capabilities, users can maximize their study time effectively.
